# Contributing to the Chiron Guild Framework

Welcome! We're excited you're here to help build the foundation of the Chiron Guild. We are currently in **Phase 0**, which means our primary goal is to build and refine the core system for a single user.

## Your First Contribution

The best way to contribute right now is to use the system to complete a task. The entire process is managed through GitHub Issues.

### Step 1: Find a Task
- Go to the **[Issues Tab](https://github.com/Chiron-Guild/chiron-guild-framework/issues)** to see the list of available tasks, which we call "Guild Ops".
- Look for issues with the `good first issue` or `help wanted` label if you're new.
- Assign the issue to yourself, or leave a comment if you'd like to claim it.

### Step 2: Do the Work
- Read the issue description carefully to understand the objectives and deliverables.
- All the information you need should be in the issue.
- If you have questions, please ask them in a comment on the issue.

### Step 3: Log Your Accomplishment
- When you have completed all the deliverables for the task, simply **close the issue**.
- That's it! Our friendly robot will take care of the rest.

## How It Works
When you close an issue, a GitHub Action automatically runs. It takes the information from the issue you just closed and adds a permanent, verifiable entry to our `registry.md` file. This creates an audit log of all contributions to the project.

This simple process is the core of our "Personal Operating System" for Phase 0. Thank you for helping us build it!
